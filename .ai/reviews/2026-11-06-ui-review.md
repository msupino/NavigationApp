# NavAid UI review findings

Review target: current `ui-review` checkout at `9eda509` (the dev snapshot), with the full current UI inspected. This is a review report; no app or tracked test files were changed.

### [MEDIUM] Light theme toolbar group captions are below readable contrast
- Where: desktop menubar dropdowns, `.tb-frame-title` and `.tb-print-label` / `.tb-frame-title` group captions; also the Display section caption; EN and HE, light theme, 1280px and 820px.
- What: computed foreground is `rgb(138, 132, 132)` (`#8a8484`) on the light menu surface, measured contrast 3.58:1. These are small 10px labels. This is below the 4.5:1 target for normal text. The value is shared across English and Hebrew labels.
- Evidence: [English light Extra layers](assets/ui-review-en-light-weather.png), [Hebrew light Display](assets/ui-review-he-light-display.png).
- Why it matters / which rule: group labels are used to scan and distinguish controls; low contrast makes the section harder to read, especially for users with low vision.
- Suggested fix: add a light-theme `.tb-frame-title` foreground override with a darker neutral that measures at least 4.5:1 against the menu background (and verify `.tb-print-label` inherits or receives the same treatment).
