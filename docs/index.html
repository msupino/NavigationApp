NavAid — CVFR Israel Map Navigation Aid & Flight Planner

NavAid is a free, browser-based CVFR Israel map navigation aid built on the Israeli aeronautical chart. Plot waypoints, draw legs, and read magnetic headings, distances and estimated times for every segment of your route. It works on desktop and mobile, installs as a Progressive Web App, and runs fully offline once loaded. Available in English and Hebrew.

תכנון מסלולי טיסה CVFR על גבי התרשים האווירי הישראלי — סימון נקודות ציון, קטעי טיסה, כיוונים מגנטיים, מרחקים וזמני טיסה. כלי חינמי לטייסים בישראל, פועל בדפדפן, נתמך גם במצב לא מקוון.

Features

  • Interactive Israeli CVFR / VFR aeronautical chart base maps
  • Waypoint, leg and note drawing with magnetic headings and distances
  • Optional published VFR reporting-point overlay
  • Printable flight plan and PNG map export
  • Offline-capable installable Progressive Web App
  • English and Hebrew interface

Israeli airfields and waypoints

Plan routes to and from Israeli airfields including Herzliya (LLHZ), Ben Gurion (LLBG), Haifa (LLHA), Megiddo (LLMG), Eilat / Ramon (LLER) and Sde Teiman (LLSD), and chart nav-waypoints across Israeli airspace.
