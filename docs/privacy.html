NavAid — Privacy Policy

Last updated: 8 June 2026

NavAid is a free, open-source CVFR flight-route planner that runs entirely in your web browser. There is no NavAid server and no NavAid account — the app is static files served from GitHub Pages.

What we collect

Nothing is sent to us. NavAid has no backend and no analytics operated by NavAid. Your routes, waypoints, notes and settings are stored only in your browser's local storage on your own device unless you explicitly enable one of the optional Google Drive sync features described below.

Google Drive (optional)

If — and only if — you choose to connect Google Drive, NavAid uses the drive.appdata permission to store navaid-routes.json, containing your saved routes, in a hidden application-specific folder in your own Google Drive. If you separately enable “Sync settings too”, portable preferences are stored in navaid-settings.json. This includes the flight-plan pilot, aircraft, licence and contact profile so it is available on your other connected devices. Current versions exclude AI API keys and the flight-plan filing destination. If an older version copied an AI key into the settings file, the next successful settings sync removes that legacy copy.

  • This permission gives NavAid access only to the file it creates in that hidden app folder. NavAid cannot see, read, or modify any other files in your Google Drive.
  • The data stays in your Google account. NavAid does not transmit it to any NavAid-operated server or any third party.
  • Authorization happens through Google's standard sign-in; NavAid never sees your Google password. Access tokens are kept in memory for the session only.
  • You can disconnect at any time, and you can delete the stored data from Google Drive → Settings → Manage apps ("Delete hidden app data").

NavAid's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Map and chart data

Map tiles and aeronautical charts are loaded directly from their providers (flight-maps.com, Esri, OpenStreetMap). Those providers may receive standard web requests (e.g. your IP address) as part of serving tiles, governed by their own privacy policies. NavAid is not affiliated with them.

Children

NavAid is a general-audience aviation tool and is not directed at children.

Changes

This policy may be updated; the "Last updated" date above reflects the latest revision.

NavAid — מדיניות פרטיות

עודכן לאחרונה: 8 ביוני 2026

NavAid הוא מתכנן מסלולי טיסה CVFR חופשי ובקוד פתוח, הפועל כולו בדפדפן שלך. אין שרת של NavAid ואין חשבון NavAid — האפליקציה מורכבת מקבצים סטטיים המוגשים מ-GitHub Pages.

מה אנו אוספים

שום דבר אינו נשלח אלינו. ל-NavAid אין צד-שרת ואין כלי ניתוח נתונים (analytics) המופעל על ידי NavAid. המסלולים, נקודות הציון, ההערות וההגדרות שלך נשמרים באחסון המקומי של הדפדפן, על המכשיר שלך, אלא אם הפעלת במפורש אחת מאפשרויות הסנכרון האופציונליות עם Google Drive המתוארות להלן.

Google Drive (אופציונלי)

אם — ורק אם — תבחר לחבר את Google Drive, ‏NavAid משתמשת בהרשאת drive.appdata כדי לשמור את navaid-routes.json, המכיל את המסלולים השמורים שלך, בתיקייה מוסתרת וייעודית לאפליקציה בתוך Google Drive שלך. אם הפעלת בנפרד ״סנכרן גם הגדרות״, העדפות ניידות נשמרות ב-navaid-settings.json. הן כוללות את פרטי הטייס, המטוס, הרישיון והקשר של תכנית הטיסה, כדי שיהיו זמינים במכשירים מחוברים אחרים. הגרסאות הנוכחיות אינן כוללות מפתחות API של כלי ה-AI או את כתובת היעד להגשת תכנית הטיסה. אם גרסה ישנה העתיקה מפתח AI לקובץ ההגדרות, הסנכרון המוצלח הבא יסיר את העותק הישן.

  • הרשאה זו מעניקה ל-NavAid גישה אך ורק לקובץ שהיא יוצרת באותה תיקיית אפליקציה מוסתרת. ‏NavAid אינה יכולה לראות, לקרוא או לשנות קבצים אחרים ב-Google Drive שלך.
  • הנתונים נשארים בחשבון Google שלך. ‏NavAid אינה מעבירה אותם לשום שרת המופעל על ידי NavAid ולא לצד שלישי כלשהו.
  • האימות מתבצע דרך מנגנון ההתחברות הסטנדרטי של Google; ‏NavAid לעולם אינה רואה את סיסמת Google שלך. אסימוני הגישה נשמרים בזיכרון למשך ההפעלה (session) בלבד.
  • ניתן לנתק בכל עת, וניתן למחוק את הנתונים השמורים דרך Google Drive ‏← הגדרות ‏← ניהול אפליקציות ("מחיקת נתוני אפליקציה מוסתרים").

השימוש של NavAid במידע המתקבל מ-Google APIs תואם ל-Google API Services User Data Policy, לרבות דרישות השימוש המוגבל (Limited Use).

נתוני מפה ותרשימים

אריחי המפה והתרשימים האווירונאוטיים נטענים ישירות מהספקים שלהם (flight-maps.com, ‏Esri, ‏OpenStreetMap). ספקים אלה עשויים לקבל בקשות אינטרנט סטנדרטיות (למשל כתובת ה-IP שלך) כחלק מהגשת האריחים, בכפוף למדיניות הפרטיות שלהם. ‏NavAid אינה קשורה אליהם.

ילדים

NavAid הוא כלי תעופה לקהל הרחב ואינו מיועד לילדים.

שינויים
